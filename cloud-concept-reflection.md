I use cloud computing every day even if I don't always know it. I use 3 cloud services regularly which is Google Drive, Messenger and Canva. With an internet connection, these apps make it easy to store files, communicate with others and create presentations or graphic designs from anyplace. One example is Google Drive, which falls under the category of Software as a Service (SaaS) due to the availability of a fully functional, cloud-based storage and file management application accessible via a web browser or mobile application, without the need for users to handle the underlying infrastructure. Its deployment model is Public Cloud, as it is available to anyone with a Google account. Messenger is also SaaS because it offers messaging and communication capabilities directly to users over the internet. It is also a Public Cloud deployment model like Google Drive as it is made available to the general public. Another example of SaaS is Canva, an online design platform that doesn't require users to install or maintain complicated software, it is also deployed through the Public Cloud, allowing users to access their projects from different devices. With cloud projects, there are usually multiple files, configurations and team members involved, so version control is essential. Without version control it would be difficult to track changes or to recover from mistakes. Developers can track all changes made with Git , so it is easier to compare different versions and restore previous working versions if necessary . GitHub also helps with collaboration by providing a common repository where team members can safely contribute. Features like branches, pull requests and code reviews enable developers to work on different tasks without overwriting each other’s work. GitHub keeps a complete history of changes, so it’s easy to see who made a particular update and why. Git and GitHub reduce errors, improve teamwork, and provide a reliable way to manage cloud infrastructure and application projects.
